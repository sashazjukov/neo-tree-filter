# neo-tree-filter is an External Sources for neo-tree nvim plugin

## goal

- it should provide an input box where user inter regex expression to filter files by filename or by its content
- when press enter in the input box- it filter by file name and show list of files (including sub directories) 
- when press F12 in the input box - it filter by file content. i.e. return list of files (including sub directories) that match the regex expression provided in the input box
- the result must be shown in the neo-tree
- it should switch neo-tree to the preview mode
