# Project Roadmap

> Neovim plugin that provides regex-based file filtering for neo-tree with an input box

## Milestones

- [ ] **Input Box UI** — Create input box for entering regex expressions
- [ ] **Filename Filter** — Filter files by regex matching filename on Enter key
- [ ] **Content Filter** — Filter files by regex matching file content on F12 key
- [ ] **Neo-tree Integration** — Display filtered results in neo-tree
- [ ] **Preview Mode** — Switch neo-tree to preview mode for results
